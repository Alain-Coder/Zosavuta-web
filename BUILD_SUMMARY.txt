GETTING STARTED
================================================================================

1. Copy .env.example to .env.local
2. Add Firebase credentials (free Firebase project available)
3. Run: pnpm install
4. Run: pnpm dev
5. Visit http://localhost:3000

See QUICKSTART.md for detailed setup instructions.
